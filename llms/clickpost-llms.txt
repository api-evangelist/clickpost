# Clickpost Implementation Guide Documentation

> ClickPost is simple shipping API for the Aramex API, FedEx API, Delhivery API, Ecom Express API, and more. Compare rates, manifest shipments, track packages. We help companies implement Logistics Intelligence to deliver a superior customer experience. We automate all our customer's logistics processes while using data driven learnings to improve their supply chain processes.
